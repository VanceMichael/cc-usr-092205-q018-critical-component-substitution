# 关键部件替代验证

控制先进制造关键部件替代、验证和在役产品影响。

## 资料约定

`contracts/domain.schema.json` 描述共享资料的字段结构，`fixtures/domain.json` 提供不含真实个人信息的业务样例。读取模块统一加载这些资料，并校验领域标识、版本、参与方、事实和约束等必要字段。

当前资料反映以下领域事实：

- 先进制造业发展强调提升产业链自主可控水平
- 制造业高质量发展依赖现代化产业体系
- 产业能力需要建立在长期工程与供应链协同之上
- 关键零件断供后，采购方可能找到尺寸相同的替代件并希望马上投产
- 尺寸相同不等于材料与性能一致，设计人员需要核实材料与性能
- 替代件可能超出既有认证范围，质量部门需要确认认证仍然有效
- 售后人员需要确认已经出厂的产品是否受到替代影响
- 制造工程团队按产品构型审理每一次替代，把设计基线、供应商批次、材料证明、工艺参数、检验计划、样机试验、认证范围、库存和产品序列连接起来

资料同时约定以下约束：

- 替代申请、构型影响分析、验证放行、在役追溯构成替代审理的基本环节
- 临时偏离、图纸升级、供应商更名、返工及撤回都必须明确影响的批次
- 同一库存不能同时分配给不兼容产品
- 样机试验失败立即冻结尚未装机的部分
- 设计、质量、采购和生产分别签署自己的判断
- 管理层比较等待原件、自制或替代时，直接看到交期、验证缺口与在役风险
- 装机人员只拿到对当前序列号真正有效的批准版本

## 本地校验

运行项目自带测试可确认样例资料符合约定。仓库不保存账号、密钥、连接串或真实身份资料。
