# 关键部件替代验证

控制先进制造关键部件替代、验证和在役产品影响。

## 资料约定

`contracts/domain.schema.json` 描述共享资料的字段结构，`fixtures/domain.json` 提供不含真实个人信息的业务样例。读取模块统一加载这些资料，并校验领域标识、版本、参与方、事实和约束等必要字段。

当前资料反映以下领域事实：

- 关键零件断供后，采购方可能提供尺寸相同的替代件并要求马上投产
- 制造工程团队按产品构型审理每一次替代，连接设计基线、供应商批次、材料证明、工艺参数、检验计划、样机试验、认证范围、库存和产品序列
- 临时偏离、图纸升级、供应商更名、返工及撤回都必须标明影响的批次
- 同一库存不能同时分配给不兼容产品，试验失败立即冻结尚未装机部分
- 设计、质量、采购和生产分别签署自己的判断，装机人员只能拿到对当前序列号真正有效的批准版本
- 管理层比较等待原件、自制或替代时需要直接看到交期、验证缺口与在役风险

## 本地校验

运行项目自带测试可确认样例资料符合约定。仓库不保存账号、密钥、连接串或真实身份资料。
